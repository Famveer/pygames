# Cómo pedir ayuda

El personal del curso está muy comprometido con tu aprendizaje. Estamos aquí para ayudarte y ofrecemos los siguientes recursos de apoyo:

* Para **preguntas administrativas** (por ejemplo, sobre fechas de entrega o interpretación de las instrucciones de una tarea); para **preguntas técnicas** sobre programación o las tecnologías; para preguntas sobre **ideas enseñadas en clase** o **preguntas generales** sobre el curso: siéntete libre de escribir al profesor o coordinar una reunión con el personal por correo.

* Para cuando te **sientas confundido**, tengas problemas de programación, no puedas formular una pregunta o quieras consejos sobre tu trabajo: siéntete libre de escribir al profesor o coordinar una reunión con el personal por correo.

* Para un **problema personal** relacionado con la calificación, asistencia o problemas de equipo: siéntete libre de escribir al profesor o coordinar una reunión con el personal por correo.
