# Videojuegos con PyGame
{: .fs-9 }

El objetivo general de este curso es brindar a los estudiantes las bases necesarias para comprender y estudiar el desarrollo de videojuegos usando Pygame.
{: .fs-6 .fw-300 }

---
¡Descubre el poder del desarrollo de videojuegos con Python y Pygame! Este curso te enseña a construir juegos 2D interactivos desde cero. Aprenderás conceptos básicos de programación, principios de diseño de juegos y técnicas de gráficos en tiempo real mientras creas proyectos atractivos. Obtendrás experiencia práctica usando Pygame para desarrollar mecánicas de juego, animation, sistemas de collision e interacciones con el usuario. Únete a nosotros para convertir tus ideas en experiencias jugables.

Al finalizar el curso, los estudiantes habrán adquirido:

1. Una comprensión de los conceptos fundamentales del desarrollo de videojuegos, incluyendo game loop, manejo de event, sistemas de sprite, detección de collision y manejo de state.
2. Experiencia práctica en el diseño, construcción, depuración y optimización de juegos 2D usando Python y Pygame.
3. La capacidad de analizar y discutir la arquitectura de un juego, técnicas de programación y decisiones de diseño usadas en juegos indie y arcade modernos.
